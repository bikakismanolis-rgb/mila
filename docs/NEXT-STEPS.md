# Τι κάνεις τώρα

Τρία βήματα, με τη σειρά. Κανένα δεν κοστίζει και κανένα δεν χρειάζεται
έγκριση από κάποιον.

---

## 1. Εγκατάσταση και deploy — 5 λεπτά

Άνοιξε γραμμή εντολών στον φάκελο του project και τρέξε:

```bash
cd D:\app\emailmessenger
npm install
git push origin master
```

Το `npm install` κατεβάζει τα πακέτα Capacitor και Tauri που μπήκαν στο
`package.json` αλλά δεν υπάρχουν ακόμα στον δίσκο σου.

Το `git push` στέλνει τον κώδικα στο GitHub. Το Vercel το βλέπει μόνο του και
ξεκινάει build μέσα σε δευτερόλεπτα — δεν χρειάζεται να του πεις τίποτα.

**Έλεγχος:** μπες στο vercel.com, δες το build να γίνεται πράσινο, μετά άνοιξε
το `https://mila-web-ivory.vercel.app/privacy`. Αν φορτώσει η σελίδα, πέτυχε.

---

## 2. Το migration στη βάση — 5 λεπτά

1. Άνοιξε `https://supabase.com/dashboard/project/jxjrggyjdqgbodvlqdte/sql/new`
2. Άνοιξε το `supabase/migrations/0006_account_deletion.sql`
3. Αντίγραψέ το **ολόκληρο** και επικόλλησέ το στο παράθυρο
4. Πάτα Run

**Αν δεις `permission denied for table users`,** τρέξε αυτό και ξαναδοκίμασε:

```sql
alter function public.delete_my_account() owner to postgres;
```

**Έλεγχος:**

```sql
select proname from pg_proc
where proname in ('delete_my_account', 'export_my_data');
```

Πρέπει να γυρίσει δύο γραμμές.

---

## 3. Δοκιμή από το κινητό σου — 10 λεπτά

Άνοιξε το `mila-web-ivory.vercel.app` από το τηλέφωνό σου.

- Φαίνεται σωστά ή είναι ζουμαρισμένο; (Αν είναι ζουμαρισμένο, κάτι πήγε
  στραβά στο deploy — πες μου.)
- Chrome → μενού → «Εγκατάσταση εφαρμογής». Πρέπει να μπει στην αρχική οθόνη
  με το μωβ εικονίδιο.
- Φτιάξε **δοκιμαστικό** λογαριασμό, στείλε ένα μήνυμα στον εαυτό σου.
- Ρυθμίσεις → Download my data. Πρέπει να κατέβει αρχείο JSON.
- Ρυθμίσεις → Delete my account, γράψε DELETE. Πρέπει να σε πετάξει έξω και
  να μην μπορείς να ξαναμπείς.

**Μη δοκιμάσεις τη διαγραφή με τον κανονικό σου λογαριασμό.** Δεν γυρίζει πίσω.

## Μετά από αυτά

Δεν χρειάζεται τίποτα άλλο για να το δώσεις σε ανθρώπους. Στέλνεις το link,
το εγκαθιστούν από τον browser, τελείωσε. Χωρίς store, χωρίς εταιρεία,
χωρίς κόστος.

Πριν το δείξεις σε **αγνώστους**, συμπλήρωσε τα placeholders στο
`apps/web/public/privacy/index.html`: επωνυμία ή όνομα, διεύθυνση, χώρα,
email επικοινωνίας, και το region της Supabase (φαίνεται στο
Project Settings → General).

Για φίλους και γνωστούς που ξέρουν ήδη ποιος είσαι, μπορείς να τα αφήσεις
προς το παρόν και να τα συμπληρώσεις όταν αποφασίσεις.

## Και μετά, με τη σειρά προτεραιότητας

1. **Push notifications.** Χωρίς αυτά κανείς δεν θα γυρίσει δεύτερη φορά.
2. **Πραγματικοί χρήστες.** Τριάντα άνθρωποι που το χρησιμοποιούν θα σου πουν
   περισσότερα από έξι μήνες σχεδιασμού.
3. **Εταιρεία και stores** — μόνο αν το βήμα 2 πάει καλά. Δες το
   `DISTRIBUTION.md`.
